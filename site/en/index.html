FAQ

Frequently asked

Only what you need to know before downloading.

Why does Windows show a SmartScreen warning?

That is the SmartScreen prompt for an unsigned binary. The project is open source, so you can review the code yourself; once signing secrets are configured, releases are Authenticode-signed automatically.

Do I have to uninstall the old version first?

No. The Windows installer updates in place with a compact progress indicator and an automatic restart. The portable build backs up, replaces and applies the update the same way, and restores the previous build if anything fails. Settings, subscriptions and VPN credentials stay in your user profile.

Do I need to bring my own nodes?

Yes. KumoRoute only provides the client; it does not include or sell nodes or subscription services. Bring your own lawful Clash/Mihomo configuration.

Where is my data uploaded?

Nowhere. Settings, subscriptions, logs and statistics stay on the local machine (%APPDATA%\KumoRoute). There is no account system and no background upload.

Which platforms are supported?

v0.8.1 ships Windows (installer and portable), Linux (AppImage and deb) and macOS (universal dmg). No mobile build yet.

VPN or system proxy?

The VPN page offers proxy only, VPN only and both together. After connecting, KumoRoute sends a real HTTP request to verify connectivity; if the tunnel is up but the network is unusable, it disconnects and restores the previous proxy.

Do backups include the VPN password?

No. JSON backups contain settings, remote subscriptions and local YAML files; Windows VPN credentials stay in the system credential manager. A safety backup is taken before restoring.

What if a node times out?

Retest it or run the whole group test. The proxies page shows success rate, jitter and the last failure reason, and nodes that time out twice in a row are excluded automatically.

Can I upgrade from the older MyClash build?

Yes. On first launch your old data is migrated, so credentials and settings survive the rename.
