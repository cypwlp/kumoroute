回報問題或留言

KumoRoute 沒有帳號或客服系統。問題與建議會直接寫到公開的 GitHub Issues —— 除了你主動貼上的內容，本站不會上傳任何資料。

請先移除訂閱連結、節點網址、IP 位址、VPN 憑證與完整日誌。安全性漏洞請改用下面的「安全性問題」私下回報，不要公開張貼。

送出前，先準備這些資訊

  1. 先看一下 常見問題，說不定已有解答。
  2. 記下設定頁顯示的版本號、作業系統與裝置型號。
  3. 寫下重現步驟、預期結果與實際結果；有截圖會更好。
  4. 若要附診斷檔，請先用程式內的匯出功能（會自動移除訂閱網址、IP 與敏感端點）。

選擇回報方式

🐞回報錯誤自動帶入錯誤回報範本並標記為 bug 💡功能建議自動帶入建議範本並標記為 enhancement 🔒安全性問題私下回報漏洞，不會公開細節
