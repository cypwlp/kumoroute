KumoRoute 隱私政策

最後更新：2026-11-12

KumoRoute 是獨立、開源的 Mihomo 桌面客戶端。本政策說明 KumoRoute 如何處理資料。

1. 我們不收集什麼

KumoRoute 不要求註冊帳號，不包含廣告 SDK，也不提供節點或訂閱服務。KumoRoute 不會自動上傳你的訂閱連結、節點、流量紀錄、瀏覽網域、日誌或設定。

2. 儲存在本機的資料

以下資料只儲存在你的電腦：

  • 應用程式設定、訂閱連結與本機 YAML 配置
  • mihomo 執行設定與日誌
  • 系統代理的原始設定備份
  • 本機流量統計、節點測速歷史與事件紀錄
  • 可選的熱門網域／規則命中統計
  • 當機紀錄

預設資料位置為 %APPDATA%\KumoRoute（Windows）或平台的應用程式資料目錄。你可以從設定頁開啟資料資料夾或清除統計。

3. 網路連線

KumoRoute 可能連線至：

  • GitHub：檢查更新、下載程式或 mihomo 核心
  • 你自行提供的訂閱網址：更新 Clash／Mihomo 配置
  • 你在日誌或設定中開啟的第三方網址

這些第三方服務可能依其隱私政策取得你的 IP 位址、User-Agent 或請求時間。KumoRoute 無法控制第三方的資料處理方式。

4. 可選統計

熱門網域與規則命中排行預設關閉。啟用後，相關資料仍只保存在本機，且可由使用者匯出或清除。KumoRoute 不會將統計資料傳送到伺服器。

5. 診斷資料

當程式發生錯誤時，KumoRoute 可在本機寫入當機紀錄。使用者可主動匯出診斷檔；匯出內容會移除訂閱網址、IP 位址與日誌中的敏感端點，且不會自動上傳。是否將診斷檔提供給開發者完全由使用者決定。

6. 第三方元件

KumoRoute 內置 mihomo 核心，依 GPL-3.0 授權使用。第三方名稱與商標歸其各自權利人所有。KumoRoute 與其他客戶端或服務沒有隸屬、代理、背書或合作關係。

7. 政策變更

本政策可能隨功能更新而調整；最新版本會公佈於官方網站與原始碼倉庫。

8. 聯絡方式

如有隱私相關問題，請透過 GitHub Issues 聯絡：https://github.com/cypwlp/kumoroute/issues
