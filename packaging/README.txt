KumoRoute v0.8.3 — 輕量 Mihomo 桌面客戶端（Windows x64 免安裝版，Rust/Tauri；相容 Clash 配置）

使用方法
1. 解壓縮到任意資料夾（請保持 KumoRoute.exe、core\、與程式同層）
2. 雙擊 KumoRoute.exe
3. 到「訂閱」貼上你的 Clash 訂閱連結（或匯入本機 YAML）
4. 回「概覽」打開「系統代理」

提示
- 首次執行可能出現 Windows SmartScreen 提示：更多資訊 → 仍要執行（本程式未簽名）。
- 關閉視窗會最小化到托盤，從托盤選單可退出。
- 若系統代理開關打開後又被關掉，是其他安全軟體在守護代理設定，請關閉其代理守護。
- 統計資料只保存在本機；可在「統計」頁匯出 CSV／JSON 或清除。
- 設定頁可切換跟隨系統／深色／淺色主題，以及繁體中文／简体中文／English；偏好會保存在本機。
- Windows 版可新增／編輯／刪除系統內建 VPN；首次登入後憑證由 Windows 認證管理員加密保存，支援清除憑證、自動關閉系統代理，以及計量網路與漫遊選項。
- VPN 頁可切換「只用代理／只用 VPN／兩者共存」；連線後會做真實 HTTP 驗證，VPN 建立但網路不可用時會自動斷線並恢復原本系統代理。
- 設定頁提供 IPv6／DNS 診斷、DNS 與代理出口 IP 比對、DoH／DoT 衝突提示與一鍵修復；修復後會重新載入核心。
- 「訂閱」頁可設定 6／12／24 小時自動更新、立即更新全部訂閱，以及匯出／還原 JSON 備份；核心重載失敗會自動回滚設定。備份不含 Windows 認證管理員內的 VPN 憑證。
- 設定頁可檢查更新；每個版本第一次發現新版本時會顯示非強制更新視窗，使用者確認後才下載並啟動安裝檔。未簽名版本仍可能出現 SmartScreen／Gatekeeper 警告。
- 安裝版更新會以 NSIS 原地更新模式覆蓋舊版，只顯示精簡進度並自動重啟，不必先解除安裝；設定與 VPN 憑證會保留。ZIP 版請先退出程式，再解壓新版覆蓋原資料夾。
- 當機紀錄保存在本機 logs 目錄，設定頁可匯出去識別化診斷資料。
- 設定目錄：%APPDATA%\KumoRoute
- 從舊版 MyClash 升級時，首次啟動會自動沿用並遷移原有設定。

內置說明
- 已內置 GeoIP/GeoSite 資料庫（geoip.metadb、geosite.dat），導入訂閱即可使用，無需聯網下載 geodata。
- 核心若異常退出會自動重啟（60 秒內最多 5 次）；core.log 超過 2MB 自動輪轉為 core.1.log。
- 代理節點延遲顯示更新時間、成功率、抖動與最近失敗原因，支援單節點重測與過期自動重測；大型節點清單分段載入。
- 每個策略組可選固定節點／自動選擇／最低延遲；連續兩次逾時的節點會自動排除，群組測速可並行並中途取消。
- 日誌支援搜尋、只顯示警告／錯誤與重複訊息合併；沒有 IPv6 預設路由時會自動停用核心 IPv6。
